# Watershed Runoff & Pollution Model
![Uploading image.png…]()

An environmental engineering model that estimates stormwater runoff and pollutant loads across different land uses.

### Features
- SCS Curve Number rainfall-runoff estimation.
- Runoff volume and pollutant loading calculations.
- Comparison of baseline and runoff-retention scenarios.
- Input validation and event-level reporting.


### Applications
Watershed management, stormwater planning, and preliminary pollution assessment.
